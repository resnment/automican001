# Automican — employee constellation redesign

## User-approved direction, 2026-10-15

A premium sci-fi public website for AI employees hired or custom-built for Bangladeshi Companies, Organizations, Institutions, or Personal needs. Replace all previous roles and departments. Remove Offices from the audience line. Increase small fonts. Add role-specific illustrated avatars that raise a hand and introduce themselves on hover, keyboard focus, or tap, with Hire and Build paths. Research current agent SDKs/frameworks/platforms and explain interoperability without claiming untested universal compatibility.

## Audit before implementation

- Confirmed readability problem: supporting text, card labels and tags in the existing CSS often use 7–12px; primary explanatory copy uses 12–14px. New baseline: body 16px, hero 19px, utility labels 11–12px minimum, form controls 16px.
- Confirmed content mismatch: existing 30-role software-delivery taxonomy is not a recognizable employee catalog for the requested audience. Replace it entirely with everyday business/institutional/personal roles.
- Confirmed inquiry mismatch: organization is required for every visitor. Add audience selection, allowing personal visitors to omit an organization.
- Aesthetic finding (taste, user requested): charcoal/mint flat cards underserve the requested classy sci-fi direction. Adopt ink-blue layered surfaces, pearl typography, champagne actions and restrained glacial cyan/lilac illumination.
- Preserve: email inquiry review/download, draft retention, app-owned dialogs, accessible validation, local assets, honest data claims and no fabricated pricing.

## Composition

An editorial hero beside a staged AI employee constellation; a filterable employee gallery; a bespoke-build section; an evidence-linked framework library; an A2A/MCP interoperability layer; process and FAQ. The avatar is the signature, not decorative dashboard telemetry. Human approval remains explicit for consequential work.
